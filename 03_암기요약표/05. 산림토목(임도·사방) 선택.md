## Ⅰ. 임도

### 용어 ★
- 종류: **간선임도 · 작업임도 · 산불진화임도** / 소유: 국유·공유·사유임도
- 곡선: 단곡선 · 복심곡선 · **반향곡선** · **배향곡선** (모듈 p.6, 2021·2023년 두 번이나 용어를 고쳤으니 출제 가능성 높음)
  - **반향곡선** = 반지름 작은 원호 직전·직후에 반대 방향 곡선이 이어진 형태, **S-커브**, **종단기울기 완화** 목적 (모듈 정의)
  - **배향곡선** = 상반되는 방향의 곡선을 연속시켜 서로 반대로 맞물려 굽은 2개의 곡선, **헤어핀 커브**
  - ⚠️ 일부 교재는 "헤어핀(배향곡선)이 종단 완화용"이라고 설명합니다. 이 시험은 **모듈 기준** 채점이므로 위 정의로 외우세요.
- 노체: 노상 · 노체 · 포장층 · 길어깨
- 배수: 겉도랑 · 속도랑 · **옆도랑(측구, L형·U형)**

### 구조·시설기준 ★

| 설계속도 | 종단기울기 (일반/특수) | 최소곡선반지름 (일반/특수) |
|---|---|---|
| 40km/h | 7 / 10% | 60 / 40m |
| 30km/h | 8 / 12% | 30 / 20m |
| 20km/h | 9 / 14% | 15 / 12m |

| 항목 | 기준 |
|---|---|
| 설계속도 | 20~40km/h |
| 유효너비 | **3m** (배향곡선지 6m 이상) · 길어깨·옆도랑 각 0.5~1m |
| 포장 시 특수지형 종단기울기 | **18%**까지 |
| 배향곡선 반지름 | **10m** 이상 |
| 횡단기울기 | 미포장 **3~5%**, 포장 **1.5~2%** |
| 합성기울기 | 12% 이하 (불가피 15%, 포장 18%) |
| 대피소 | 약 **300m** 간격, 너비 5m, 유효길이 15m 이상 |
| 차돌림곳 | 너비 **10m** 이상 |
| 배수구(횡단) | 지름 **1,000mm** (필요 시 800mm) 이상, 통수단면 최대홍수유출량의 **2배** 이상 |
| 성토 비탈 | 1 : 1.2~2.0 |
| 산불진화임도 | 유효너비 **3.5m** 이상, 대피소 200m 간격·너비 6m |
| 작업임도 | 유효너비 2.5~3m, 종단기울기 최대 **20%** |

### 시공 기준 ★
- 종단기울기 **8% 이상 → 콘크리트 포장** 원칙 · 포장 폭 3.0m, 두께 0.2m (곡선부 확폭) · 쇄석 부설 10cm 내외
- 능선부 종단기울기 **4% 이내**, 성토 없이 절토
- **물넘이포장(세월교)**: 계곡부 종단 3~5%
- 헤어핀: 산지 횡단경사 **40% 이하**, 진입·출구 종단 10% 이내
- 산불진화 차량 교행 → 노폭 3.5m 이상
- 건당 공사비 **2억원 이상** → 실시설계 기준
- 계획 주기(법): 전국임도기본계획 10년, 임도설치계획 5년

## Ⅱ. 사방

### 총론
- 사방사업법 정의: 황폐지, 사방사업, 사방시설, 사방지(**시·도지사 또는 지방산림청장** 지정·고시), 산사태, 토석류
- 근대 사방의 효시: **1907년 창의문 주변 식목**
- 큰 구분: 산지사방 · 야계사방 · 해안사방 · 생활권사방 · 특수지사방

| 구분 | 공종 | 핵심 |
|---|---|---|
| 기초공사 | 비탈다듬기 | **위에서 아래로** 시공 · 부토 3m 이상이면 속도랑·땅속흙막이 먼저 |
| | 단끊기 | 계단 형성 |

### 사방댐 (불투과형 중력식) ★

| 항목 | 기준 |
|---|---|
| 대수면(상류면) | 수직 또는 1:0.1~0.2 |
| 반수면(하류면) | 1:0.2~0.5 (흙댐 1:1.5~2.0) |
| 방수로 | 역사다리꼴, 옆 기울기 1:1, 최대홍수유량의 **200~500%** |
| 댐마루 두께 | 소계류 0.8m / 일반 **1.5m** / 전석 유송지 2.0m / 대규모 토석류 2.0~3.0m |
| 신축줄눈 | 댐 길이 **25m 초과** 시 |
| 물빼기구멍 | 지름 20~40cm, 최상단은 방수로 바닥에서 1.5m 이하 · 3㎡당 1개 |
| 앞댐 | 중복높이 본댐 높이의 **1/3~1/4** · 간격 L ≥ (1.5~2.0)(H + t) |
| 메쌓기댐 / 혼합쌓기댐 | 최대 **4m** / 5m 전후 |

**안정조건 4가지**: ① **전도** — 합력선이 제저 **중앙 1/3** 이내 통과 ② **활동** ③ **제체 파괴** ④ **기초지반 지지력**

### 사방 공식 ★

| 구분 | 공식·계수 |
|---|---|
| Manning | V = (1/n) R^(2/3) S^(1/2) · n: 콘크리트 0.012~0.017, 흙수로 0.017~0.025 |
| Chezy | V = C√(RS) |
| Bazin | 산지계류 α = 0.0004, β = 0.0007 |
| Kutter | n = 0.03~0.035 |
| **합리식** | Q = (1/360) C·I·A (A: ha) · **사방댐 설계에 가장 많이 씀** · 유출계수 급경사 산지 0.75~0.90, 산지하천 0.75~0.85 |
| 시우량법 | 유거계수 황폐지 0.8, 소면적 1.0 |
| 그 밖 홍수량 | 비류량법, 홍수위흔적법 |
| 유달시간 | Kirpich, Rziha(S ≥ 1/200), Kraven(S ≤ 1/200), Kerby(산림 n = 0.80) |
| 소류력 | τ = w·R·S |
| 웨어 | 직사각형, 삼각형(C = 0.6), 사다리꼴 |

(V 유속, R 경심 = 통수단면적 ÷ 윤변, S 수면기울기, C 유출계수, I 강우강도 mm/h, A 유역면적)

## Ⅲ. 심화 — 임도 용어·절차 (임도 모듈 p.5–11)

- 구분: 국유(국가) · 공유(지자체) · **사유(산주·경영자 자기 부담, 분수림 설정자 포함)**
- 곡선: **단곡선**(하나의 원호, 가장 많이 씀) · **복심곡선**(반지름 다른 두 곡선이 같은 방향) · 반향곡선 · 배향곡선 · **완화곡선**(외쪽물매·나비넓힘을 원활하게)
- 노상 = 포장층 아래 약 **100cm** 균일 토층 · 소단 = 긴 비탈면 안정·침식 방지
- 겉도랑 = **개거**(노면 비스듬히 횡단) · 속도랑 = **암거·컬버트**(노면 아래 횡단) · 옆도랑 = 측구 · 도수로 · 물넘이포장(노면 호형 포장) vs 세월시설(노면 아래 관거)
- 절차: 기본계획(산림청장 10년) → 간선임도 설치계획(5년) → 노선선정 → **타당성평가(필요성·적합성·환경성)** → 사업계획(전년 8월 말) → 확정(전년 11월 말) → 산주동의 → 설계·시공·감리 → 준공 → 평가
- 작업임도: 2.5t 소형 트럭 수준 저규격 · 산불진화임도 노폭 3.5m 이상(교행)

### Ⅴ-3. 사방사업법 시행규칙 [별표] 사방사업 설계·시공 기준 (2025.2.21 개정)
