## 문서 규칙

- **기본 문서는 모두 Markdown(`.md`)입니다.** 공부·수정은 md 파일로 합니다.
- **PDF·한글(hwpx) 원문은 [`08_PDF원문모음/`](./08_PDF원문모음/)에 모았습니다.** 폴더 구조는 01_공식자료와 같습니다.
- 파일·폴더 이름은 `번호_제목` 형식으로 통일했습니다 (예: `03_암기요약표/01_조림.md`).
- 버전 관리는 `main` 브랜치 하나로만 합니다. 이전 판은 따로 보관하지 않고 git 기록으로만 남깁니다.

## 모의고사.html 쓰는 법

`05_모의고사/모의고사.html`을 더블클릭하면 브라우저에서 열립니다. 인터넷 연결은 필요 없습니다.

- **실전 모의고사**: 필수 4과목 + 선택 1과목, 과목당 20문항(677문항 중 무작위 100문항), 150분 타이머 → 과목별 점수, **40% 과락**, **60% 평균** 판정, 해설
- **과목별 연습**: 과목·파트를 골라 한 문제씩 풀고 바로 해설 확인 (Part 1 기본 / Part 2 심화 / Part 3 참고자료 / Part 4 산림기사 기출·실무 / Part 5 법령·지침 원문)
- **2021 공개문제 38제**: 실제 출제 형식 문제를 전 과목 또는 과목별로 풀이
- **오답노트**: 틀린 문제가 자동 저장되고, 다시 맞히면 빠집니다 (이 브라우저에만 저장)

문제 md(04_예상문제, 05_모의고사/00 공개문제)를 고치면 아래 순서로 html을 다시 만듭니다.

```bash
python3 tools/format_questions.py   # 보기·해설 줄 정리
python3 tools/build_quiz.py         # 05_모의고사/모의고사.html 생성
```

인쇄용 PDF가 필요하면 `brew install pandoc typst` 후 `bash tools/build_pdfs.sh`를 실행합니다. 결과는 `08_PDF원문모음/00_MD변환본/`에 생기며 git에는 올리지 않습니다.
