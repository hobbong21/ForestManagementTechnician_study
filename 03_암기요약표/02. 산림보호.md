# 산림보호 암기 요약표

> 기준: 2026 학습모듈 「산림보호」(V07.26). ★ = 고빈도 · 🆕 = 2026.8.30 개정 반영 부분

## 1. 기상 피해

| 피해 | 핵심 |
|---|---|
| 볕데기(피소) | 수피가 평활한 수종(**오동나무·호두나무·가문비나무**), **남서방향** 임연부 |
| 치묘 열해 | 7~8월 · 약한 수종: 전나무·가문비·편백 / 강한 수종: 소나무·곰솔·측백 |
| 만상(晩霜) | **봄** 늦서리 · 약한 수종: 잎갈나무류·오리나무류·자작나무류 |
| 조상(早霜) | **늦가을** 이른서리 |
| 상륜 | 만상 때문에 한 해에 연륜이 **2개** 생기는 현상 |

## 2. 대기오염 피해

| 오염물질 | 증상 |
|---|---|
| SO₂ | 엽맥간 괴사, 잎 앞·뒷면 모두, 연반 2~4일 뒤 · 늦봄~초여름 가장 민감 |
| O₃ | 책상조직 손상 → **잎 앞면** |
| HF | 엽록괴사, 갈색 밴드 |
| PAN | **잎 뒷면 은회색** 광택 |

## 3. 산불 ★

| 항목 | 내용 |
|---|---|
| 종류 | 지중화 · **지표화**(가장 흔함, 4~7km/h) · **수관화**(V자형, 진화 곤란) · 수간화 |
| 발생 조건 | 상대습도 **50% 이하** 발생 쉬움, **25% 이하** 수관화 대부분 |
| 시기 | **3~4월**, 13~16시에 약 49% |
| 소화약제 | **MAP**(제1인산암모늄), DAP(제2인산암모늄) · 헬기 살포 시 물보다 약 2배 효과 |
| 내화수림대 | 폭 **30m** 내외 · 맞불은 최후 수단 |

| 내화력 강함 | 내화력 약함 |
|---|---|
| 은행나무, 잎갈나무, 분비나무, 가문비나무, 개비자나무, 아왜나무, 굴거리나무, 동백나무, 사철나무, 가시나무, 회양목, 피나무, 고로쇠, 참나무 | **소나무, 곰솔, 삼나무, 편백**, 녹나무, 구실잣밤나무, 아까시나무, 벚나무, 능수버들 |

## 4. 산림보호법 시행령 과태료 🆕 (1차 / 2차 / 3차)

| 위반 | 금액 |
|---|---|
| 신고 없이 숲가꾸기 벌채 | 100 / 300 / 500만원 |
| 허가 없이 입산통제구역 출입 | 10만원 |

| 나무병원이 처방전 없이 농약 사용 | 150 / 300 / 500만원 |

| 바이러스 | 모자이크병 |
| 선충 | **소나무재선충병** |

### 11-1. 산림재난방지법 (법률 제21622호, 2026.5.12 개정)

| 항목 | 기준 |
|---|---|
| 산림재난 정의 | **산불 · 산사태 · 토석류 · 산림병해충** |
| 산림인접지역 | 산림으로부터 **100m 이내** 토지 (산불 규정 적용 범위) |
| 계획 | 산림재난방지 기본계획(산림청장)·지역계획(시·도지사·지방산림청장) 모두 **5년마다** |
| 산불조심기간 | 산불위험지수가 높은 기간 → 산림청장·지자체장이 지정, 그 중 특별대책이 필요한 기간 = **산불특별대책기간** |
| 산불경보 | 「재난안전법」에 따른 **산불재난 국가위기경보**, 발령권자 **산림청장** |
| 행위 제한 (제18조) | 산림·산림인접지역에서 불 피우기·불 가지고 들어가기, 흡연·꽁초, 정해진 기간 풍등 날리기 금지 |
| 산사태 기초조사 | 산림청장이 **5년마다** → 필요한 지역은 산림재난방지기관장이 실태조사 |
| 산사태취약지역 | 지정권자: 국유림 **지방산림청장** / 공·사유림 **시장·군수·구청장** · 이의신청 결정 **20일** 이내 · 주소불명 시 **30일 이상** 공고 · 취약지역·대피소 **연 2회 이상** 현지점검 |
| 방화 벌칙 (제76조) | 타인 산림 **5~15년** 징역 · 자기 산림 **1~10년** · 자기 산림 불이 타인 산림으로 번지면 3~10년 · 실화 **3년 이하 또는 3천만원 이하** · 미수범 처벌 |
| 과태료 (제79조) | 불 피우기·불 가지고 입산·풍등 **200만원 이하** · 담배·꽁초 **70만원 이하** · 화기 소지 금지명령 위반·허가받고 소방서에 안 알리고 불 피우기 **30만원 이하** |
| 기관 | **한국산림재난안전기술공단** 신설 (구 재선충 모니터링센터 등 업무 흡수) |

> 2026.5.12 개정 중 일부 조문(제76조·제79조 등)은 **공포 6개월 후(2026.11.12)** 시행 → 11.7 시험에는 위 현행 기준.

### 11-2. 소나무재선충병 방제특별법 (법률 제20751호)

| 항목 | 기준 |
|---|---|
| 소나무류 | 소나무 · **해송** · **잣나무** + 산림청장 고시 수종 |
| 훈증 | 감염목·감염우려목을 벌채·집재 → 약제 투입 → **비닐 밀봉** |
| 반출금지구역 (제9조) | **시장·군수·구청장**이 지정 · 발생지역 + **5km 이내** 범위에서 대통령령이 정한 거리(모듈 **2km**) · **행정동·리 단위** |
| 이동 예외 | 훈증·파쇄 후 확인, 예방약제 약효 **2년 이상** 기간 내 주사 + 연구기관 확인증(조경수·분재 굴취목) 등 |
| 비반출금지구역 이동 | **생산확인표** 발급 필요 (위반 200만원 이하 벌금) |
| 방제방법 (제11조) | **항공방제 + 감염목 벌채**, 벌채목은 **훈증·파쇄·소각** · 방제 **14일 전** 공고 |
| 벌칙 | 반출금지구역에서 이동 **1년 이하 / 1천만원 이하** · 감염목 판매·미신고 500만원 이하 |
| 과태료 | 모두베기 후 조림 미이행 → **조림비용 전액** |

### 11-3. 산림병해충 방제규정 (산림청고시 제2026-97호, **2026.9.8 제정**)

| 항목 | 기준 |
|---|---|
| 예찰조사 주체 | **국립산림과학원장** (고정조사구·상습발생지·선단지) |

## 12. 🛡️ 산림보호학 핵심 비교 정리표 (수험생 빈출)

### 1) 나무 질병의 3대 병원체 비교
| 병원체 종류 | 주요 특징 | 치료 및 약제 | 대표 질병 |
| :--- | :--- | :--- | :--- |
| **진균 (곰팡이)** | 산림 수병의 약 80% 차지. 포자로 번식 | **살균제** (보르도액, 다이센 등) | 잣나무 털녹병, 모잘록병, 그을음병 |
| **세균 (박테리아)** | 세포벽 있음. 비바람이나 전정 가위로 전파 | **항생제** (스트렙토마이신 등) | 뿌리혹병(근두암종병), 불마름병 |
| **파이토플라스마** | 세포벽 없음. 매미충 등 곤충이 매개 | **테트라사이클린계** 항생제 주사 | 대추나무 빗자루병, 오동나무 빗자루병 |

### 2) 산림 화재 4대 유형 비교
| 산불 형태 | 타는 부위 | 전파 속도 및 위험도 | 진화 난이도 |
| :--- | :--- | :--- | :--- |
| **지표화 (地表火)** | 낙엽, 잡초, 작은 관목 | 가장 흔하며 바람 따라 확산 | 일반 진화선 구축 가능 |
| **수관화 (樹冠火)** | 나무 꼭대기(가지·잎) | 불티 날림(비화) 동반, 가장 위험 | 직화 진화 불가, 방화선 필요 |
| **수간화 (樹幹火)** | 나무 줄기 자체 | 보통 고사목이나 동공 부위 | 벌목 또는 주수 소화 |
| **지중화 (地中火)** | 땅속 부식토, 이탄층 | 연기 없이 은밀히 타들어 감 | 진화 최난관 (파헤치고 주수) |
